## Intelligence without representation
### 分析
智能可以不依赖对世界的显式表征，也不需要中央控制系统  
![](png/Pasted%20image%2020260929170749.png)

生物进化历程，专家知识只是进化的很小的一段时间，很长的时间进化于与环境互动，做出反应

### 现状
现在已经没人再谈论复制整个人类智慧的全貌了。取而代之的是专注于特定的子问题，例如知识表示、自然语言理解、视觉，甚至是更专业的领域，如真值维护系统或计划验证。这些子领域的所有工作都是以人类在这些领域中执行的任务作为基准。在仍然留在人工智能领域的梦想家（那些不是梦想金钱的人）中，普遍有一种感觉：有一天，所有这些部分都会最终融合到一起，我们将看到“真正”的智能系统的出现。 

|        | 传统功能分解     | 消解架构             |
| ------ | ---------- | ---------------- |
| 感知的角色  | 产出符号化世界描述  | 分散在多处，无统一 " 输出 " |
| 决策的位置  | 中央符号信息处理器  | 每个活动层就地自触发       |
| 规则形式   | 规则库 + 变量匹配 | 硬连线的固定拓扑 FSM     |
| 世界状态来源 | 人预先抽象成原子命题 | 频繁感知，用世界本身当模型    |

传统的做法：视觉——规划——控制（视觉产出一份描述给规划，规划产出一份指令给控制。这种 " 模块之间大量接口 " 正是靠表征完成的。）

现在取消掉这些层，不需要彼此调用——层不是节点图里上下游互相调用的关系，而是平行运行、各自被世界触发。

### 感知与智能的关系
输入是否已经被抽象成为其预设的形式

> [!tip]+ 主张
> 1. 难易颠倒了，感知和运动技能才是难题，" 剩余的小部分智能 "（问题求解、语言、专家知识、推理）才是小部分
> 2. 系统的构成应该由感知实际能产出什么来决定

人类感知到的世界对于机器人系统：

1. 对下：不是机器人真实感知到的东西（硬件不同）
2. 对上：也不是人类真正在用的东西（人类描述的东西不可靠）

> 第二条异议在今天的对应物相当直接。多模态模型是在人标注、人能看见的数据上训练的，因此天然继承了 " 人类 Merkwelt"——包括它漏掉的东西，模型往往也说不清。而可解释性研究用探针从网络内部挖出模型从没 " 报告 " 过的结构，说明同样的落差在网络上也存在：它能做出来，但说出来的和实际在算的不是一回事。
> 
> 所以这段话今天仍然有效，只是位置换了——它原本是说 " 别信研究者替机器写下的感知世界 "，现在还可以读成 " 别太信模型自己讲的那套 "。

### 真正的系统
- 一个生物必须适当地及时地应对其动态环境中的变化
- 生物应当有适应性（世界属性的微小变化不应导致生物行为的完全崩溃，相反随着环境的不断变化,应只期望生物的能力逐渐发生变化）
- 一个生物应该能够保持多个目标，并根据其所处的环境，改变其正在积极追求的具体目标（可以适应环境，也可以利用偶然的机会）
- 有所作为，应该存在某种目的

接口（相邻模块之间传递东西的约定，是数据契约，数据格式），这个接口的规定现在是有问题的（接口的数据类型依靠研究者进行指定，且为了测试其中一个模块，所有模块都需要先被构建）

所以纵向进行构建：先构建一个非常简单的完整自主系统（“它能够感知周围的物体,并远离它们,如果在前进路径上探测到东西就会停下。建立这个系统仍然需要将其分解为各个部分,但不需要在“感知子系统”、“中央系统”和“行动系统”之间有明确的区分。实际上,可能存在两 个将感知与动作相连接的独立通道 (一个用于启动运动,一个用于紧急停止), 所以没有一个地方像传统意义上那样由“感知”输出世界的表征。” ( [Brooks, p. 147](zotero://select/library/items/MTPBTERG)) ( [pdf](zotero://open-pdf/library/items/F34GA3BL?page=9&annotation=GFIZQB8T))）

重点在于接口中传递的东西不再具有语义信息（中央系统——智能必须汇聚到一处，这个落点）

## Attention Is All You Need

### token
每个词都有其对应的向量（在多维坐标系中，含有语义信息）  
之后对词进行位置编码：

$$
PE_{(pos,2i)}=sin(pos/10000^{2i/d_{\mathrm{model}}})\quad PE_{(pos,2i+1)}=cos(pos/10000^{2i/d_{\mathrm{model}}})
$$

现在每个词都有其向量信息（语义和位置）

---

目的：并行同时提高效率

“Transformer 是第一个完全依赖自注意力来计算其输入和输出表示的 转换模型,而无需使用序列对齐的 RNN 或卷积” ( [Vaswani 等, 2023, p. 2](zotero://select/library/items/GAYPI3GK)) ( [pdf](zotero://open-pdf/library/items/W6KVM7T3?page=2&annotation=S4ZNMG88))

![](png/Pasted%20image%2020260929145346.png)

$$
\operatorname{Attention} (Q, K, V) = \operatorname{softmax} (\frac {Q K ^ {T}}{\sqrt {d _ {k}}}) V\tag{1}
$$

- Q：token 想关注的信息
- K：提供的信息
- V：token 查询键下对应的值

$Q1\cdot K2$：第一个 token 对第二个 token 的关注程度（**相关性**）  
$Q1\cdot K2/\sqrt{d_k}$：由于 token 的维度不同，统一一下向量点积得到的值  
之后使用 $softmax$ 将每个 token 的注意力归一化（概率权重）  
${softmax} (\frac {Q1 K2 ^ {T}}{\sqrt {d _ {k}}}) V2$：token 1 以这样的权重取 token 2 的信息

$$
\begin{equation}
    0.15V1+0.84V2+0.01V3=新向量
\end{equation}
$$

这个就是第一个 token 在融合上下文信息之后的向量表示

---

### 多头注意力
模型会**并行**做多次注意力计算：多头注意力

$$
\begin{equation}
    \begin{aligned}\mathrm{MultiHead}(Q,K,V)&=\mathrm{Concat(head_{1},...,head_{h})}W^{O}\\\mathrm{where~head_{i}}&=\mathrm{Attention}(QW_{i}^{Q},KW_{i}^{K},VW_{i}^{V})\end{aligned}
\end{equation}
$$

### 之后的
- add：将注意力的结果与原始数据相加（残差网络）
- norm：归一化（调整在 0~1 之间）

前馈网络：FFN：$\begin{equation}\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2\end{equation}$ : 通过前馈神经网络的 ReLU 激活函数将线性的映射掰弯  
之后再接上 add 和 norm  
![](png/Pasted%20image%2020260929152905.png)

这里就是编码的部分，让模型实现输入语义的理解

文章中编码器为 N=6 个相同层的堆栈（多头注意力 + 前馈神经网络）

此时模型对输入的**上下文以及含义有了全面深入的理解**  
这个理解会作为**解码器中的 K,V**

### 解码器
初始时的 Q 为 start，表示开始任务，之后根据解码器中的 k,v 输出第一个值，作为新的 Q  
之后以此类推，新的输出结果都加入 Q 中，再结合注意力机制进行输出（已有输出结合输入信息之后新的向量表示）

掩码多头注意力机制（训练时掩盖正确结果）

之后将输出的向量再次经过类似编码器中的东西，最后将得到的向量通过词表查到

## RT 1
通用机器人模型的关键在于 " 开放式、任务无关的大规模训练数据 + 能吸收这些数据的高容量架构 "

| 维度     | Brooks (1991)  | RT-1 (Brohan 等, 2023) |
| ------ | -------------- | --------------------- |
| 反对的对象  | 显式世界模型 + 符号推理  | 语言解析/视觉/控制的流水线        |
| 内部状态   | 主张模块化、最小化      | 大规模分布式表示，但无符号         |
| 能力来源   | 手工设计的包容架构，不学习  | 数据驱动、任务无关的大规模训练       |
| 与世界的关系 | 具身、在线、感知直接驱动动作 | 离线模仿人类演示，3 Hz 闭环输出    |
| 语言     | 没有             | 语言指令作为条件输入            |

将原始的动作指令离散化——每个动作维度离散为 256 个区间（手臂 7 维 + 底盘 3 维 + 1 个模式变量，模式在 " 控手臂/控底盘/终止 " 之间切换），用标准交叉熵 + 因果掩码训练

流程：语言指令与顺序的 6 张图片变为长度为 48 的序列，序列中每一个元素为长度为 512 维度的向量，在 transform 中输出 11 个离散的动作序列

" 开放式、任务无关的大规模真实机器人数据 " 与 " 能吸收它的高容量且实时的架构 " 这两件事同时做成，给出数据多样性>数据量、异构数据可吸收两条可操作的结论

- 优点：
	- 可以有效吸收大量数据，并且随着数据数量和多样性的增加而扩展
	- 以往发布的基 准方法更能有效地推广到新的任务、物体和环境
	- RT‑1 可以成功吸收来自模拟环 境和其他机器人形态的异构数据，而不会牺牲原有任务的性能，并且在面向新场景的泛化能力上有所提升
- 不足：
	- 可能无法超越示范者的表现（因为是一种模仿学习的方法）
	- 其次，对新指令的泛化能力仅限于以前见过的概念组合，并 且 RT‑1 还无法泛化到完全未见过的新动作
